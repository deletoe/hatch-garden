# 圆润造型 / Rounded skin

这 23 个 SVG 从本仓库重绘前的提交 `acc07ff599daf6a4cd6f20a74253194c2853ac40` 原样保留，包括小猪的四种姿态、母鸡的六种姿态、小鸡的四种姿态，以及蛋与蛋壳。乔治仍为椭圆身体，不含助听器。暂停页可以切换整套造型；场景、特效与声音共用，游戏规则不随皮肤改变。

These 23 SVGs preserve the artwork from commit `acc07ff599daf6a4cd6f20a74253194c2853ac40`, before the reference redraw. The pause menu switches the complete character and egg set. Shared scenery, effects, sound, and game rules remain the same. Runtime textures load on the first selection and are reused thereafter.

佩奇和乔治属于同人形象，底层角色权利声明见 [CHARACTER_NOTICES.md](../../CHARACTER_NOTICES.md)。这套圆润母鸡和小鸡为项目最初的原创美术。
