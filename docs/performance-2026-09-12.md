# 暂停与密集鸡群性能修复

2026-09-12，Apple M5 / Node 26.4 / Chrome 153。旧版基线为 `3de511b`。以下是本机测量，不代表手机或其他浏览器的帧率。

## 定位与改动

- 旧版暂停只冻结模拟；场景仍逐帧复制实体、更新全部精灵与阴影。现在暂停同时停止 Phaser 刷新循环和 TweenManager，恢复时清除累计步长，并扣除动画时钟中的暂停时间。独立 ResizeObserver 允许暂停时按窗口变化重绘一次。
- 旧版每个固定步为最高分和 UI 分别复制实体，显示层再复制一次；UI 每帧重复写入文字、图标 URL 和属性。现在 UI 只订阅分数和设置变化；同一状态的实体快照复用，变化后才重新生成。静止鸡蛋不重复设置位置、尺寸和深度；角色纹理只在姿态变化时切换。
- 旧版每只母鸡都重新生成、排序候选蛋位，并扫描所有已有蛋和预留位置。现在候选网格只在尺寸变化时重建，一次下蛋共用空间占用索引，依次预留后统一创建。仍然优先母鸡脚边、就近避开已有蛋，剩余空位不足时接收部分批次。
- 短音效改为复用最多 8 个播放器，另有 1 个背景音乐播放器；同一固定步的批量孵化只请求一次破壳声音。暂停、静音分别管理，不因在暂停菜单打开声音而播放音乐。旧版频繁创建播放器会造成额外资源压力，本次没有据此断言浏览器存在不可回收的内存泄漏。
- 普通破壳/成长装饰最多 40 个；满屏庆祝保留完整 51 个对象，但同一时间只播放一组庆祝。重开时销毁装饰并清理动画。鸡、蛋的实际数量和得分不受装饰预算影响。

## 可重复的模拟基准

运行 `npm run benchmark`；可用 `npm run benchmark -- 1800` 延长到 30 分钟。对照旧检出目录：`GAME_SOURCE_ROOT=/path/to/old/checkout npm run benchmark`。临时转译文件在退出时清理，不进入生产包。

固定随机种子 123，以 60 Hz 推进 180 秒，每 13 步下蛋一次；每秒采样实体数。计时包含一次完整批量下蛋规划和创建，均为毫秒；不包含浏览器绘制。下表记录首轮对照数据，运行负载会影响具体耗时。

| 视口 | 版本 | 下蛋 P50 | 下蛋 P95 | 下蛋最慢 | 整段模拟耗时 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1280 × 720 | 旧版 | 24.53 | 34.40 | 39.19 | 18,332 |
| 1280 × 720 | 修复后 | 0.20 | 0.31 | 0.78 | 331 |
| 1920 × 1080 | 旧版 | 231.27 | 328.41 | 595.24 | 172,946 |
| 1920 × 1080 | 修复后 | 0.49 | 1.01 | 2.01 | 927 |

两个视口的旧版与新版得分分别都是 5,865 / 12,700；采样实体峰值分别都是 1,030 / 2,622，成年鸡峰值 574 / 1,595，蛋峰值 204 / 443。单元测试额外对照朴素距离搜索，覆盖不同缩放、密集预留，以及 100 个位置已有 98 个时只能再下两颗的情况。

## 浏览器与长时间运行

Playwright 驱动本机 Chrome；测试专用拦截只在开发页面暴露控制器，不写入生产代码。

- 1280 × 720、先用正常模拟动作生成 90 秒的鸡群：旧版约 2 秒内调用实体快照 367 次、HUD 产生 854 次 DOM 变更；新版分别约 117 次和 1 次。暂停后的游戏快照/显示同步不再逐帧执行，刷新循环处于停止状态。
- 保留 51 个庆祝对象暂停 10 秒，模拟时间、装饰坐标/透明度与动画时钟均不变。恢复首帧没有补算暂停时间，之后特效完成并回收。
- 暂停时依次调整到 390 × 844、844 × 390、1920 × 1080、1280 × 720：游戏世界、canvas 与视口一致，无水平或垂直滚动，模拟时间不变，循环继续保持停止。
- 50 次暂停/恢复、模拟 `visibilitychange` 事件及其与手动暂停的组合、进入/退出全屏、重开均通过；无页面 JavaScript 异常。隐藏事件为自动化注入，并非手机锁屏实测。
- 另在 1920 × 1080 密集鸡群下恢复真实刷新和每 217 ms 下蛋输入。暂停前后分别测量 10 秒，中间暂停 8 秒：均更新 600 帧，场景 CPU 更新中位数均 0.8 ms，P95 分别 1.7 / 1.6 ms；结束实体数 2,409 / 2,435。该 CPU 计时不包含 GPU 绘制；帧数来自真实刷新循环，未观察到恢复后逐步变慢。
- 加速运行 30 分钟：每个固定步均执行模拟、事件处理、视图同步、深度排序和装饰动画；每 13 步下蛋一次。暂停真实渲染循环并用虚拟动画时钟加速，因此此项验证对象回收，不作为实时 GPU 帧率测试。

| 模拟分钟 | 存活实体 | 显示对象 | 装饰 | GC 后 JS 堆 MiB |
| ---: | ---: | ---: | ---: | ---: |
| 5 | 989 | 2,019 | 40 | 21.75 |
| 10 | 929 | 1,910 | 51 | 21.81 |
| 15 | 923 | 1,921 | 74 | 21.92 |
| 20 | 1,008 | 2,048 | 31 | 21.92 |
| 25 | 987 | 2,007 | 32 | 21.90 |
| 30 | 985 | 2,022 | 51 | 21.96 |

每次采样均满足显示对象数 = 背景 1 + 实体数 × 2 + 装饰数；事件队列为空，素材纹理始终 21 个，场地点击监听器始终 1 个，音频播放器最多 9 个。采样装饰峰值 85 个，动画峰值 85 个，30 分钟得分 62,056。最后恢复真实循环并操作暂停/继续，未出现异常。堆数据不包含 GPU 和原生媒体内存。

`npm run test`：19 项通过。`npm run build`：类型检查和静态生产构建通过，主脚本 gzip 约 328 KB。浏览器查看了密集鸡群、暂停、手机竖屏和加速运行结束后的截图。Safari、手机真机、操作系统锁屏和长时间热降频仍需对应设备实测。
